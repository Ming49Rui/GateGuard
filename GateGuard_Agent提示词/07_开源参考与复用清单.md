# GateGuard 开源参考与复用清单

核查日期 2026-11-23。以下 URL 和文件在所列提交核验；固定提交是参考快照，不等于推荐将开发分支直接作为生产依赖。运行依赖由 A/C 在 Ubuntu 验证并锁定可复现版本。未克隆或运行这些仓库的安装脚本。

## 推荐组合与边界

推荐从 libbpf-bootstrap 改造小型 BPF 底座，采集参考 BCC，精细执行参考 KubeArmor；C 使用现有 btrfs CLI 并参考 Snapper，D 使用 pandapower 生成可选仿真输入。高层策略生成、解释、审核、恢复编排和评测由团队完成。不要将完整 Go/Kubernetes 控制平面直接搬入 Python 单机项目。

每次复制/改造必须记录 upstream_url、commit、path、文件许可、原版权、本地落点、修改说明、团队贡献和所跑验证；C 维护 docs/provenance.md 与 THIRD_PARTY_NOTICES，角色在 handoff 中提供条目。依赖调用、代码复制和设计参考分别写清。

BPF 内核许可声明与源码授权需分别核查：[Linux BPF licensing](https://docs.kernel.org/bpf/bpf_licensing.html)。不能移除原 SPDX/版权或仅因改写为 Python 就忽略来源；无明确授权的代码不列为可复制底座。最终发布按实际文件与组合核验，不作全仓统一许可证假设。

核查仅确认公开源码与许可入口，尚未证明这些版本在 Ubuntu/openEuler 环境可编译、可运行或性能适合。开工时先做最小 PoC，保留失败与兼容调整。
