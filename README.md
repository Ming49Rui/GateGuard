# GateGuard · 守门

面向电力边缘服务的可解释最小权限防护与可验证恢复系统。

本项目按 **A/B/C 三名参赛成员协作**，组长为其中一人。本仓库保存项目设计、任务入口和统一 Agent 提示词。设计版本 **3.0**，2026-11-23。

## 工作链路

电力输入 → Ubuntu 模拟业务 → 真实文件访问采集 → DEF 质检封包 → 组长在 Windows 学习规则 → 高层 profile 回传 Ubuntu → 编译与绑定 → 实际权限验证 → 独立损坏恢复与评测。

权限学习当前为可解释规则归纳，输出可读权限策略。电压/电流是业务输入，主机访问行为才是学习依据。Windows 本地与 Ubuntu 分别使用独立 Python 环境；BPF、cgroup 和 Btrfs 实验在 Linux VM 执行。

## 开工顺序

1. 所有任务执行者读协作入口和契约，再打开相应编号目录中的任务链接。
2. G0 并行做环境、模型/fixture、工程骨架和数据/场景准备。
3. G1 小批真实数据通过质检后扩大采集；G2 跑通 Windows 学习与 Ubuntu 执行。
4. G3 独立验证有真实损坏的恢复；G4 冻结测试、对照与消融，整理课堂和竞赛交付。

当前内容是待实现约定，Ubuntu/openEuler 的运行能力以实际探测和实验记录为准。
