## 交付与协作

- 各任务按 G0 并行启动；G1 小批真实数据通过检查后再批量采集。
- 核心接口使用契约 3.1，修改接口交 B 汇总，根依赖交 C 汇总。
- 交接记录放 `docs/handoffs/B.md`，写清文件、接口、验证命令及结果、未测/不支持项和下一位所需输入。
- 组长负责实际策略学习、调参、审核与最终结果分析。

当前仓库为任务与设计起点，软件实现和 VM 实测由组员按提示词完成。
